Core Framework & Language
React 19: Framework utama pengembangan antarmuka (UI) berbasis komponen.
TypeScript: Bahasa pemrograman dengan pengetikan ketat (strict typing) untuk memastikan keamanan data struktur kegiatan, peserta, dan filter.
Vite 6: Tool bundler modern berkecepatan tinggi untuk development dan production build.
2. Styling & UI Components
Tailwind CSS v4: Framework utility-first CSS untuk penataan tata letak (layout), warna, dan tipografi.
Refined Neo-Brutalism Style: Konsep visual khas dengan border tegas, solid drop shadows (neo-shadow), serta palet warna yang nyaman di mata (eye-friendly).
Lucide React: Library ikon SVG modern yang memberikan indikator visual konsisten di setiap menu.
Motion (motion/react): Library animasi untuk transisi antar-tampilan, pemunculan modal, dan efek hover interaktif.
3. Data Visualization & Analytics
Recharts: Library grafik reaktif interaktif untuk menampilkan:
Komparasi persentase kegiatan MPR vs DPR.
Top 5 Instansi dengan partisipasi terbanyak.
Tren kegiatan tahunan (2023–2026).
Distribusi segmen peserta dan jenis kegiatan.
4. Export & Document Processing
XLSX (SheetJS): Memungkinkan fitur impor file Excel serta ekspor tabel monitoring ke format spreadsheet .xlsx.
jsPDF & AutoTable: Generator dokumen untuk fitur pencetakan laporan kegiatan langsung ke format PDF.
5. Backend & Intelligence Integration
Node.js & Express: Server backend ringan untuk mengelola API endpoint dan pemrosesan data.
Google GenAI SDK (@google/genai): Integrasi model AI Gemini untuk pemrosesan ringkasan cerdas, ekstraksi data, dan sinkronisasi laporan.
